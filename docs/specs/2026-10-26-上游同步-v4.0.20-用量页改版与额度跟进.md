## 设计要点

### 1. 定价同步 222 → 232
- `git worktree` 检出 v4.0.20 → `CC_SWITCH_DIR=<worktree> bash scripts/sync-pricing.sh` → python 对账（预期 +10 / −0 / 改 3）。
- +10：gemini-4-argon、minimax-m3.1-flash、qwen3.6-27b、qwen3.7-flash、qwen3.8-omni-flash、deepseek-v4.1-flash、kimi-k3.1-pro、kimi-k3.1-pro-highspeed、k3.1-pro、k3.1-pro-highspeed；改 3：kimi-k3 / k3 缓存写入 0 → 3.00，step-5-preview 缓存读取 0.05 → 0.10。
- 教训（Sonnet 5 那次上游 seed 错过 1.5 倍）：逐条对官方价格页。内置表只给库里没有的模型兜底，库里的价永远优先，所以对不上的不在本地改，记下来报给用户（要改得去上游）。

### 2. 叠加层查价不分大小写（#8414）
- **根因**：`loadPricingIfStale` 按库里原样大小写建 `pricingExact`，`ModelId.pricingCandidates` 产出的候选全是小写 → 按界面显示名原样入库的自定义价（如 `GLM-5.3-Flash-EXL3`）精确匹配永远落空；前缀匹配用 `hasPrefix` 也区分大小写，上游 `LIKE` 不区分。结果是叠加层退回内置表或记 0。
- **改法**：建键时转小写；同一小写键撞车时先读到的留下（我们的 SELECT 和上游 `= ? COLLATE NOCASE` 都按表的自然顺序扫，先到先得一致）。`pricingIds` 用小写键。OmpOverlay 用日志自带的 cost、不查价，不受影响。
- **测试**：库里放大写自定义价，叠加行用小写模型名能算出该价；前缀匹配大写行同样命中；撞车时取先插入的那行。

### 3. Claude 额度钥匙串选条目（#8764）
- **根因**：只按服务名 `Claude Code-credentials` 查、不带账户。钥匙串里有几条同名条目时可能拿到只存 `mcpOAuth` 的旧条目 → 直接报「凭据中缺少 OAuth 条目」，也不回退文件。
- **改法**（逐条照上游 `read_claude_credentials_from_keychain_with`）：依次试 `[-a $USER]`、不带账户；退出码 0 且解析出 token → 用它；退出码 44（没有这个条目）、没有 Claude token、不是 UTF-8 → 试下一个；其他失败（起不来进程、别的退出码）→ 不再试钥匙串；钥匙串都不行 → 读 `~/.claude/.credentials.json`。纯规则放 Shared，runner 注入；App 层只负责起 `security` 进程（stderr 接空设备，免得管道写满卡死）。
- **测试**：当前账户命中只调 1 次且参数带 `-a`；账户条目为 44 / 只有 mcpOAuth / 非法 JSON / claudeAiOauth 为空 → 第 2 次不带 `-a`；其他退出码立即放弃钥匙串；`USER` 为空只调 1 次不带 `-a`；两次都失败交给文件。

### 4. 会话来源名

- **页面结构**（照上游）：页头 → 范围栏（时间在前 → 应用码片 → 供应商 / 模型级联菜单）→ 概览面板（指标条 + 图表，点指标切换图表画的指标）→ 明细面板（请求日志 / 供应商 / 模型三个页签带数量；请求日志有状态码筛选、列菜单、每页 10 / 20 / 50）→ 请求详情抽屉。
- **保留的定制**：页头右侧 = 刷新间隔 + 趋势图样式（柱形 / 面积，见下）+ 额度徽标；热力图常驻（概览面板里，趋势图下方）；不放同步按钮、设置抽屉、定价、重建、空状态。

- **显示设置的存取**：上游 `UsageTrendChart` 和页面都通过 `get_settings` 读 `usageDisplay`（列显隐、图表样式）和 `visibleApps`。桥接新增 `get_settings`：`usageDisplay` 从本应用 UserDefaults（`embed.usageDisplay`，JSON 字符串）读，只放行 `requestLogColumns`（列 id → bool）和 `trendChartType`（字符串）；`visibleApps` 只读镜像 `~/.cc-switch/settings.json` 里的同名字段（只收 bool 值；文件缺失 / 坏 → 不给，前端按上游默认全显示）。写入走已有的 `set_setting("usageDisplay", <JSON 字符串>)`，写完失效 `["settings"]` 查询。

### 6. Antigravity 额度改查 `retrieveUserQuotaSummary`
- **上游**：v4.0.18 起查 `retrieveUserQuotaSummary`，两组（Gemini；Claude 和 GPT 共用）× 两个窗口（5 小时、每周），带重置时间；User-Agent 必须含 `antigravity/cli/<版本 ≥ 1.2.0>` 才回 Gemini 那组（读不到本机 agy 版本时用 1.4.6）；认识的桶 `gemini-5h` / `gemini-weekly` / `3p-5h` / `3p-weekly`，别的跳过。
- **10-26 实测**（用 IDE 的登录，只读额度）：请求体 `{}` → 403「没有有效许可」；`{"project": <loadCodeAssist 给的项目>}` → 200。UA `cc-usage/… (antigravity/cli/1.4.6)` 回两组；IDE 风格的 UA 只回 Claude/GPT 一组。这个免费档账号只回 `gemini-weekly`、`3p-weekly`（没有 5 小时桶），旧接口的重置时间与每周桶一致——旧数字其实是每周窗口。
- **改法**：沿用现有令牌刷新与 `loadCodeAssist`；额度改发 `retrieveUserQuotaSummary {project}`；UA = `cc-usage/<版本> (antigravity/cli/<agy 版本>)`，agy 版本每个进程探测一次（PATH 及 `~/.local/bin`、`/opt/homebrew/bin`、`/usr/local/bin` 里找 `agy --version`，5 秒超时），找不到用 1.4.6。解析规则放 Shared（剩余比例钳到 0…1、已用 = (1 − 剩余) × 100、按固定顺序排、认不出任何桶 → 失败，保留上次结果）。30 秒节流和 stale-if-error 不变。
- **菜单栏**：额度码片按档位勾选，键 `agy.quota.<桶 id>`，标签 `Gemini 5H` / `Gemini 7D` / `Claude 5H` / `Claude 7D`（窗口按时长写，和 Claude / Codex 一致）。旧键迁移：`antigravity.quota.Gemini` → `agy.quota.gemini-weekly`，`antigravity.quota.Claude` / `GPT-OSS` → `agy.quota.3p-weekly`（去重）；启动时做一次，幂等。
- **测试**：两组四档解析与排序；只有每周桶；未知桶跳过；全不认识 → nil；剩余比例越界钳位；重置时间带小数秒；agy 版本解析（`1.4.6`、`v1.5.0`、杂词、无版本）；UA 格式；码片迁移（三种旧键、去重、其他键原样、幂等）。

### 8. 菜单栏 W / M 改按自然日回溯
- **现状**：W / M = `now − 7×86400` / `now − 30×86400`（滚动 168 / 720 小时）；主窗口的 7d / 30d = 今天往前 6 / 29 个自然日的零点起。同叫「7 天」，两边对不上。
- **前人意图**（`f7b1919`）：原来是日历「本周 / 本月」，月初时本周跨回上月、比本月还多，改滚动窗口是为了保证「月 ≥ 周 ≥ 日」。按自然日回溯同样保证这点（起点 30 天 ≤ 7 天 ≤ 今天零点，终点都是现在）。
- **改法**：`UsageWindow.lookbackStart(days:now:calendar:)` = 今天零点往前推 N−1 个日历日，再取那天的第一刻（跨夏令时、零点被跳过的时区都对）。PanelModel 的 All 与按应用两处都换。
- **测试**：东京普通日；纽约春令时 / 冬令时切换前后，起点仍是当地零点、跨度是 7 个日历日；零点被跳过的时区取当天第一刻；days = 1 等于今天零点；单调（30 ≤ 7 ≤ 1）。
