# [TECHNICAL SPECIFICATION] 主窗口与菜单栏显示 Claude 套餐

## 背景
- 上游 v4.0.21 起在 Claude 官方卡片和授权中心显示套餐（`src/lib/claudePlan.ts` 的 claudePlanLabel，数据来自 Rust 侧 `credential_plan` 读凭据里的 `subscriptionType`、`rateLimitTier`）。
- 本应用原先只把凭据里的原始 `subscriptionType`（如 `max`）塞进额度档的 `planLabel`，只出现在主窗口徽标的悬停提示里，分不出 5x / 20x。
- 11-01 用户选定显示位置：主窗口 + 菜单栏。

## 设计
- `Shared/ClaudePlan.swift`：逐条照搬 claudePlanLabel 的英文默认文案——`pro` → Pro；`max` + `default_claude_max_20x` / `default_claude_max_5x` → Max 20x / Max 5x，否则 Max；`team` + `default_claude_max_5x` → Team Premium，否则 Team；`enterprise` → Enterprise；其余首字母大写；读不到为 nil。两个字段先去首尾空白（上游 Rust 侧读出来就 trim 过），类型不分大小写。
- `ClaudeCredential` 多读 `rateLimitTier`（非机密字段）；QuotaService 用 ClaudePlan 格式化后写进每个额度档的 `planLabel`。不额外读钥匙串：套餐随额度一起来，没拉过额度就不显示。
- 主窗口：`QuotaBadges` 在徽标左边放一行淡色套餐名（同上游卡片「额度块标题 = 套餐」）；悬停提示随之变成格式化后的名字。
- 菜单栏：设置面板 Claude 组的 Quota 行末尾靠右显示套餐名（`PanelModel.claudePlanLabel`）。

## 测试
- 套餐名：上游全部分支 + 大小写 / 空白 / 未知类型；空串、纯空白、nil 不给标签。
- 凭据解析读出 `rateLimitTier`。
- 变异测试 8 个变异体全部被杀（5x / 20x 对调、Team 高级席位档位、大小写、去空白、默认首字母大写、空白给标签、不读档位）。

## 2026-11-04 修订：Ultra 改名，优先用服务器下发的套餐名
- 起因：2026-10-30 官方把 Max 20x 改名 Ultra（$200/月）、Max 5x 改名 Max（$100/月），老用户自动迁移。凭据里的 `subscriptionType` / `rateLimitTier` 没变（仍是 `max` + `default_claude_max_20x`），写死的映射就继续显示 Max 20x；上游 cc-switch 到 v4.0.24 也还是旧映射。
- Claude Code 2.1.316 的做法：`/api/oauth/profile` 返回 `organization.plan_display_name`，按 `^[\p{L}\p{N}](?:[\p{L}\p{N} .+-]{0,38}[\p{L}\p{N}+])?$`（JS `u` 模式）校验，通过的存进全局配置的 `oauthAccount.planDisplayName`，显示成 `Claude <名字>`；拿不到才按 subscriptionType 回落。全局配置位置：`~/.claude/.config.json` 非空就用它，否则 `$CLAUDE_CONFIG_DIR`（缺省为家目录）下的 `.claude.json`。
- 改法：
  - `ClaudePlan.label(displayName:subscriptionType:rateLimitTier:)` 先认显示名（同一条规则；锚点写 `\A` / `\z`，因为 ICU 的 `$` 会放过结尾换行，JS 不会）；读不到套餐类型时照旧不显示，哪怕配置里留着显示名。
  - 回落映射改用新名：`max` + 20x → Ultra，其余 `max` → Max；Team / Team Premium / Enterprise / Pro 不变。
  - App 层 `ClaudeConfigReader` 与读凭据放在同一个后台任务里读配置，只取这一个字段（配置里还有邮箱等个人信息）；文件不存在或没有这个字段记 debug 日志，读失败记 error，都回落到推断。本应用从访达启动，CLAUDE_CONFIG_DIR 对它不生效，和钥匙串只查默认条目一致，只看默认位置。
- 测试：回落新名；显示名优先；不合法的显示名（首尾空白、结尾换行、尖括号、首尾是 - . +、零宽字符、下划线、41 个字符）回落；校验边界（1 / 40 / 41 个字符，首尾字符集）；没有类型不显示；配置解析（缺键、null、数字、顶层不是对象、坏 JSON）。变异体 5 个（20x 仍写旧名、忽略显示名、长度上限差一、结尾锚点用 `$`、先看显示名再看类型）全部被杀。
