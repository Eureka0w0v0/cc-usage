## 设计要点

### `get_usage_first_date`（对齐上游 v4.0.5 `get_first_usage_date`）
- 明细表 `MIN(created_at)` 转本地日，rollups 表 `MIN(date)`，两者取早；没有记录返回 null。
- 吃 app（折叠 claude-desktop）/ provider（含会话占位名）/ 模型筛选；**不吃时间窗、也不套跨源去重**——去重只会把同一笔请求换成 ±10 分钟内的另一行，跨午夜时反而把最早日推后一天。
- 本 app 另把未入库的 overlay 行算进来（cc-switch 从没开过的新机器，库空但会话日志有数据），与其余查询同口径。

### 热力图组件
- 网格、分段、分档、月份 / 星期标签逐行照搬上游：
  - 每段 53 列 × 7 行，周一开头；第 0 段右端是本周，更早的段首尾相接。
  - 段数 = 最早日期落在第几段（`spanCountFor`）；默认只画第 0 段，「Show more」展开全部。
  - 深浅按**所有段**非零天的四分位分 4 档，上下几段可以直接比。
  - 指标可切 Tokens（新增输入 + 输出 + 缓存写入 + 缓存命中）/ 请求数 / 花费；悬停卡片显示当天三项。
- 数据：先查最早日期算段数，再用钉子版本的 `useUsageTrends` 查「最早一段起点 → 现在」的按天走势。Swift 侧 `trendBuckets` 对 >24h 区间按本地日分桶、合并 rollups、空桶补 0，不需要改。
- 钉子版本缺的东西就地改写，不改上游文件（钉子校验只放行桥接文件）：
  - v7 token（`bg-surface`、`text-fg-*`、`--heat-1…4`）→ 钉子版本的 `bg-card/40`、`text-muted-foreground` 等；色阶写死成上游深色主题的值（`#38bdf8` 的 30% / 50% / 75% / 100%），embed 恒为深色。
  - `SegmentedControl` → 与工具栏应用筛选同款的分段按钮；`UsageTooltipCard` → 与走势图同款的悬停卡片。
  - 文案沿用上游 i18n key，embed 恒为英文，缺 key 时落到 `defaultValue`（上游英文原文）。
  - 钉子版本的 `useUsageTrends` 不收 `enabled`：最早日期回来前先按 1 段查；段数为 1 时查询键不变、不会重查。
- 与上游的唯一行为差异：上游只在 All 范围下用它替换走势图；这里常驻，不受时间范围影响。
