# [TECHNICAL SPECIFICATION] 内置定价补 Claude Fable 5.1（本地先行区）

## 变更背景
- 2026-09-01 Claude Fable 5.1 发布，日志 model id 为 `claude-fable-5-1`；cc-switch seed（v3.20.1 及 main）、其 DB `model_pricing`、本项目内置表均无此行。
- 上游查价为「候选精确匹配 → `model_id LIKE 'claude-fable-5-1-%'` 前缀匹配」，反向不会命中 `claude-fable-5`，故入库写 $0；本项目内置表同样缺失 → 面板对这些请求记 $0。
- 官方定价（platform.claude.com/docs/en/about-claude/pricing）：$10 / $50，缓存写 5m $12.50，**缓存读 $0.25（0.025x）**——不能照抄 Fable 5 的 $1，Claude Code 会话九成以上 token 是缓存读，抄错即 4 倍误差。

## 受影响模块
- `Sources/Shared/ModelPricing.swift`：生成区改名 `upstream`（192 条不动）+ 新增 `localExtras`（`claude-fable-5-1` / `claude-mythos-5-1` = R(10, 50, 0.25, 12.5)）+ `table = upstream.merging(localExtras)`（上游优先）。
- `scripts/sync-pricing.sh`：定位锚点改为 `static let upstream`；只重建生成区，`localExtras` 不碰。
- `Tests/ModelPricingFallbackTests.swift`（+2）、`Tests/SessionOverlayTests.swift`（+1）。

## 设计要点
- 上游优先：同一 id 两边都有时取 upstream，用户在 cc-switch 改过的价 / 上游修正的价不被本地行盖掉。
- 退场机制：`testLocalExtrasAreAbsentUpstream` 断言 `localExtras ∩ upstream = ∅`，上游收录后自动报红提醒删本地行。
- 查价链路不变：`SessionOverlay.findPricing` 先 DB 精确/前缀，再 `ModelPricing.lookup`；聚合侧 TEMP 兜底表由 `table` 灌入，对成本 ≤ 0 的行现场补算。

## 测试
- 内置表命中 fable-5-1 四个价 + `[1m]` / 命名空间变体 + mythos-5-1；与 fable-5 的缓存读不相等。
- localExtras 与 upstream 不相交；`table.count == upstream.count + localExtras.count`。
- Overlay E2E：DB 无该模型 → 回落内置表，缓存读 1M×$0.25 → total 0.252。
- 变异验证：删 fable-5-1 行 / 0.25 抄成 1 / 忘记 merge，三个变异体均须被杀。
- `sync-pricing.sh` 在当前 pin 上重跑应为 no-op（锚点改名后仍能定位，本地行保留）。
