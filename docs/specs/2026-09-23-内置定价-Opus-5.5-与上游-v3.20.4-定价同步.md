# [TECHNICAL SPECIFICATION] 内置定价补 Claude Opus 5.5 + 上游 v3.20.4 定价同步

## 变更背景
- 2026-09-23 Claude Opus 5.5 发布，日志 model id 为 `claude-opus-5-5`；cc-switch seed（v3.20.4-1 / main `8e478b2b`）、其 DB `model_pricing`、本项目内置表均无此行 → 入库与面板都记 $0。
- 候选链不会把末尾的 `-5` 当日期尾剥成 `claude-opus-5`（只剥 8 位 / 6 位 / ISO 日期），前缀兜底又是 `id-` 单向 → 查不到。是漏价，不是错价。
- 官方定价（platform.claude.com/docs/en/about-claude/pricing）：$4 / $20，5 分钟缓存写 $5，**缓存读 $0.20（0.05x）**——不是常规 0.1x 的 $0.40，也不是 Opus 5 的 $0.50；照抄 opus-5 行即缓存读 2.5 倍误差。1M 上下文无溢价；1 小时缓存写 $8、fast mode $8/$40、batch $2/$10 本表无列。
- 上游 v3.20.3-14 → v3.20.4-1 另有两个定价提交未同步：`d8e98be2`（DeepSeek V4 Pro 修回高峰档 1.32/3.96/0.044——官方撤回了路由公告，v3.20.3 提前改成的 0.3/1.2/0.006 是错价；新增 qwen3.8-2.4t-a95b / qwen3.8-27b / hy4-preview）、`42200b42`（新增 grok-4.7 / glm-5.3-flashx）。

## 受影响模块
- `Sources/Shared/ModelPricing.swift`：`localExtras` 加 `claude-opus-5-5` = R(4, 20, 0.2, 5)；`upstream` 生成区 201 → 206 条（改 1 增 5），基准 `v3.20.4-1-g8e478b2b`。
- `scripts/sync-pricing.sh`：git 仓库判断由 `[ -d .git ]` 改为 `git rev-parse --git-dir`——worktree 里的 `.git` 是文件，旧判断让基准静默写成 "unknown"。
- `scripts/{sync-pricing,check-app-types,build-embed}.sh`：全角标点紧跟的变量加花括号（非 UTF-8 locale 下 bash 把全角字节吞进变量名，报错信息丢路径），共 4 处，只影响出错提示。
- `Tests/ModelPricingFallbackTests.swift`（+1）。

## 设计要点
- 沿用本地先行区：上游优先合并；上游收录 `claude-opus-5-5` 后 `testLocalExtrasAreAbsentUpstream` 报红，届时删本地行。
- 只同步定价 seed，不动面板钉子（`CC_SWITCH_REF` 仍为 `fdbe3a85`）、不重建 embed：本区间上游在我们口径内只改了定价 seed，其余是 provider / skill / omo 与赞助商文案。
- 查价链路不变：DB 已有价始终优先；内置表只对 DB 无价或成本 ≤ 0 的行生效。

## 测试
- 内置表命中 opus-5-5 四个价 + `[1m]` / 命名空间变体；与 opus-5 的 input 不相等（`-5` 不被当日期尾剥掉）。

- 全量 137 测试通过。
